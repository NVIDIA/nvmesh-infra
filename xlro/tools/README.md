INFRA TOOLS
===========

Tools created with the use of NVMesh infra framework.

Tool delivery is available via official NVMesh packages (from compilators) or provided as executables (makeinfra.sh script).

Each tool can be used with --help for some usage documentation.

As the tools are built with the onedir option of pyinstaller, make sure the tool is in the same hierarchy as the infra/ dir after it is compiled.
